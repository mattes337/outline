# Task Management

Outline's task management system allows you to create, track, and manage tasks directly within your documents and through dedicated task pages.

## Creating Tasks

You can create a task within any document by typing `[ ] ` (a left square bracket, a space, a right square bracket, followed by a space) at the beginning of a line. This will automatically convert the line into a new task item.

Example:
`[ ] This is a new task`

Once created, you can type your task description. Tasks are automatically saved as part of the document.

## Task Management Pages

Access the main task management area by clicking on "Tasks" in the sidebar. This section is organized into three tabs:

*   **My Open Tasks:** This tab displays all tasks that are currently assigned to you and are not yet completed. Tasks are ordered by priority, which can be adjusted using drag-and-drop.
*   **All Open Tasks:** This tab shows all open (uncompleted) tasks across all documents you have access to within the team, regardless of who they are assigned to. Tasks are ordered by priority.
*   **Done Tasks:** This tab lists all tasks that have been marked as completed. This is useful for reviewing recently finished work. Tasks are ordered by their completion date (most recent first).

## Task Reordering (Prioritization)

In the "My Open Tasks" and "All Open Tasks" tabs, you can reorder tasks to reflect their priority. Simply click and drag a task up or down in the list to its desired position. The new order is saved automatically.

## Task Detail Page

Clicking on any task in the task lists will navigate you to its dedicated Task Detail Page, where you can manage all aspects of that specific task.

*   **Editing Title:** The task's title can be edited directly at the top of the page. Click on the title, make your changes, and press Enter or click outside the input field to save.
*   **Editing Body (Description):** The main description of the task can be edited using Outline's rich Markdown editor. Add details, lists, links, or any other formatting needed. Changes are saved automatically (or via a save button/blur action depending on editor configuration).
*   **Assigning Tasks:** You can assign or change the assignee for a task using the user selector dropdown. Select a user from the list to assign them the task.
*   **Completing/Re-opening Tasks:** A button at the top of the page allows you to toggle the task's status. If it's open, you can "Mark as Complete". If it's completed, you can "Re-open Task".
*   **Adding Comments:** Below the task body, there's a comments section. You can add comments to discuss the task, provide updates, or ask questions. Comments are displayed chronologically.

## Synchronization

Tasks are seamlessly synchronized between the documents where they originate and the task management pages.
*   When you create or modify a task in a document (e.g., check it off, change its text), these changes will be reflected in the "Tasks" pages after a short delay.
*   Similarly, when you update a task from the Task Detail Page (e.g., change its status, title, or assignee), the corresponding task item within the source document will also be updated automatically.

This ensures that you always have a consistent view of your tasks, whether you're working within a specific document or managing tasks globally.
